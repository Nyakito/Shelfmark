# Shelfmark

NONE OF THIS COULD HAVE BEEN POSSIBLE WITHOUT OPEN LIBRARY

For now you cant read here, these books might have intellectual property policy or might just be premium things, but as far as Opening the world to readers go, I will link each book to it's `oceanofpdf` link so that you can get access to it, either way.

## Purpose

Shelfmark is a literary bookshop finder for discovering and saving books through Open Library.

## Planned features

Title, author, and subject search; relevance/title/year sorting; cover, author, year, and edition metadata; saved-shelf localStorage collection;

## Chosen API

Open Library: [API documentation](https://openlibrary.org/developers/api), especially Search API and cover endpoints.

## Setup and run

No package dependencies. Serve this directory with a static server or Live Server and open `index.html`.

## File structure

- `index.html` — editorial discovery and search
- `saved.html` — saved book shelf
- `styles.css` — ivory, burgundy, and serif visual identity
- `js/main.js` — instructional TODOs for search, sorting, and rendering
- `js/saved.js` — instructional TODOs for localStorage
